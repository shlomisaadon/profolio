# React Portfolio

A personal portfolio built with React 17, React Router 6, Bootstrap 5, and Sass. The repository was created in December 2021, with the current source history including February 2022 commits.

## Explore the code

The interface is composed of navigation, main content, carousel, and footer components. It includes a technology-icon grid and a résumé download.

Start with [App.jsx](src/App.jsx), [the main component](src/Components/main/main.jsx), and [the navigation component](src/Components/nav-bar/nav-bar.jsx).

## Local development

The project uses Create React App 4-era dependencies. Use a Node.js version compatible with that toolchain.

```sh
npm install
npm start
```

A fresh installation has not been revalidated during the November 2026 documentation update.
